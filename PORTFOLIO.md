# Portfolio index

A short router for public repositories. See each repository for its own scope, caveats, and reproducibility notes.

## Lead public work

- **[uniprot-mcp](https://github.com/smaniches/uniprot-mcp)** — auditable UniProt MCP server with provenance, release pinning, verification, and offline replay.
- **[semantic-scholar-mcp](https://github.com/smaniches/semantic-scholar-mcp)** — typed Semantic Scholar MCP tools for literature search, citation graphs, author profiles, and recommendations.
- **[alphafold-sovereign-mcp](https://github.com/smaniches/alphafold-sovereign-mcp)** — local-first biomedical MCP over AlphaFold DB and related public sources, with explicit clinical-use limits.

## Research software

- **[pca-topology-crossdomain-replication](https://github.com/smaniches/pca-topology-crossdomain-replication)** — versioned PCA/persistent-homology replication and matched-null comparison, with explicit inferential limits and archival provenance.
- **[TopoGeoML](https://github.com/smaniches/TopoGeoML)** — topology-aware ML toolkit and preregistered graph-classification study with an honest negative headline result.
- **[cohomology-wall](https://github.com/smaniches/cohomology-wall)** — reproducibility archive for tetraquadric Calabi-Yau cohomology-jumping calculations.
- **[GROUPOID](https://github.com/smaniches/GROUPOID)** — pre-alpha aggregation prototype exploring groupoid/sheaf/Riemannian ideas for federated learning.

## AI safety / biosecurity research

- **[homology-cliff](https://github.com/smaniches/homology-cliff)** — ESM-2 protein-retrieval failure-mode study with preregistered evidence, calibration analysis, and curation limits.
